# ============================================
# 批量翻译文件使用说明
# ============================================
# 1. 每个模组以 '|模组ID' 开始，后跟四行：
#    原始名称、原始描述、翻译名称、翻译描述。
# 2. 翻译名称和翻译描述：
#    - 填写您想要的翻译内容。
#    - 留空 或写为 '# 注释' 表示删除此翻译。
# 3. 原始名称和描述仅作为参考，修改它们不会生效。
# 4. 若描述中有换行，请使用 <LINE> 标记（例如 '第一行<LINE>第二行'）。
# 5. 编辑完成后，保存文件并回到游戏设置页，点击“应用全部”。
# 6. 所有修改都会自动备份到模组的 backup 文件夹下，如有问题可恢复文件到：
#    - C:/Users/{你的用户名}/AppData/LocalLow/Videocult/Rain World/ModConfigs/ModTranslatorSave_{你的语言}.txt
# 7. 因翻译索引机制的限制，若本模组不在模组排序顶部，部分翻译可能无法生效
# 8. 以 '#' 开头的行是注释，会被忽略。
# ============================================
